# Scoop Bucket for Snipset

Official [Scoop](https://scoop.sh) bucket for **Snipset** (https://snipset.belajarcarabelajar.com) — Intelligent AI-Powered Snippet Manager and Text Expander for desktop productivity.

## How to Install Snipset via Scoop

```powershell
# 1. Add this bucket
scoop bucket add snipset https://github.com/belajarcarabelajar/scoop-snipset

# 2. Install Snipset
scoop install snipset

# 3. Update Snipset in the future
scoop update snipset
```
